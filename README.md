# Overview

Our project aims to provide user with real-time data on various weather and safety sensors to help them plan out their day and keep them safe from household hazards by provide visual and sound warning in case of any danger.

# Features
- Real-time monitoring of temperature, humidity, ultraviolet level, rain, flame and gas.
- Warning system that notfies the user with a customizable buzzer sound and LEDs.
- Mobile application with login functionality that displays the sensor readings, statistics and graphs about them.
- Component cooling system via DC Fan.
- Locally hosted database for storing the sensor readings.

# Requirements
## Hardware
- DOIT DEVIT V1 ESP32-WROOM-32 Development Board or similar microcontroller
- MB102 Breadboard 830 Point
- MQ-4 Gas Sensor Module
- Flame Sensor Module
- DHT11 (Temperature Humidity Sensor Board)
- Raindrop Sensor Module
- 2x Capacitive Touch Sensor TTP223
- GUVA-S12SD UV Light Sensor Module
- DC Fan 5V (9x9cm)
- Magnetic Buzzer 5V 12mm 2 Pin
- Green, Yellow and Red LEDs
- Carbon Resistors 1kΩ 0.25W and 220Ω 0.25W
- Wires 20 cm "Male to Female", "Male to Male", and "Female to Female" pins
- Micro USB to USB Cable

## Software
- Visual Studio - Platform IO
- Flutter
- Firebase
- HiveMQ or similar MQTT Platform
